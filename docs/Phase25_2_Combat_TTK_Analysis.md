## 3. Boss TTK

### Boss数据 (Floor 1)

```
Boss HP = 300 + 1 * 200 = 500
Boss Defense = 5 + 1 * 5 = 10
```

### TTK计算

```
Base DPS = 150
Defense Reduction = 10 / (10 + 100) = 9.1%
Effective DPS = 150 * (1 - 0.091) = 136.4

TTK = 500 / 136.4 = 3.7秒
```

**当前状态：** ⚠️ Boss战过短（目标30-60秒）

## 5. 目标TTK设计

### 设计目标

| 怪物类型 | 目标TTK | 说明 |
|----------|---------|------|
| 普通怪 | 3-5秒 | 有战斗体验 |
| Elite | 8-15秒 | 有挑战性 |
| Boss | 30-60秒 | 有史诗感 |

### 实现方案

#### 方案1: 提高怪物HP

**当前：** 史莱姆 HP = 20
**目标：** 史莱姆 HP = 80

```
新TTK = 80 / 150 = 0.53秒 (仍然太短)
```

**需要同时降低玩家DPS**

#### 方案2: 降低玩家DPS

**当前：** DPS = 150
**目标：** DPS = 30

```
新TTK = 20 / 30 = 0.67秒 (仍然太短)
```

#### 方案3: 综合调整

| 参数 | 当前 | 目标 | 说明 |
|------|------|------|------|
| 普通怪HP | 20 | 100 | x5 |
| 武器伤害 | 20 | 10 | /2 |
| 攻击间隔 | 0.2s | 0.4s | x2 |

```
新DPS = (10 + 10) * 2.5 = 50
新TTK = 100 / 50 = 2秒 (接近目标)
```
