## 2. 怪物行为分析

### AI状态机

```
IDLE (空闲)
    ↓ 距离 < 300
CHASE (追击)
    ↓ 距离 < 100
ATTACK (攻击)
```

### 行为特征

| 状态 | 行为 | 说明 |
|------|------|------|
| IDLE | 原地不动 | 等待玩家靠近 |
| CHASE | 追踪玩家 | 水平方向移动 |
| ATTACK | 攻击玩家 | 近战攻击 |

### 问题

| 问题 | 说明 |
|------|------|
| 行为单一 | 只有追击和攻击 |
| 无远程攻击 | 所有怪物都是近战 |
| 无特殊技能 | 普通怪物无技能 |

## 4. Floor成长曲线

### 当前成长公式

```gdscript
// 怪物等级修正
var multiplier = 1.0 + (level - 1) * 0.3

// 难度调整
var difficulty_mult = 1.0 + (diff - 1) * 0.2
monster_count = int(monster_count * difficulty_mult)
monster_level = max(1, diff)
```

## 8. 设计建议
