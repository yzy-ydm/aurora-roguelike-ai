| 文件/目录 | 说明 |

## 📊 数据库设计要点

### 核心表设计

- **users** - 用户信息表
- **game_saves** - 游戏存档表
- **monsters** - 怪物数据表
- **weapons** - 武器数据表
- **ai_generation_logs** - AI生成记录表

### 设计原则

1. 使用InnoDB引擎，支持事务
2. 使用utf8mb4字符集，支持完整Unicode
3. 合理建立索引，优化查询性能
4. 使用外键约束，保证数据完整性
5. 记录创建和更新时间，便于追踪

## 📝 文档要求

毕业设计答辩时需要展示：

1. **ER图** - 实体关系图，展示表之间的关系
2. **表结构说明** - 每个表的字段说明和设计理由
3. **数据字典** - 字段的详细定义和约束说明
