# 毕业论文材料目录

本目录用于存放毕业论文撰写过程中所需的各类材料。

## 📁 目录结构

```
paper_material/
├── 📂 images/          # 论文插图
├── 📂 screenshots/     # 系统截图
└── 📂 references/      # 参考资料
```

## 📁 目录说明

### images/ - 论文插图

用于存放论文中使用的各类图片：

- 架构设计图
- 流程图
- 数据库ER图
- 系统功能模块图
- 网络拓扑图
- 其他技术图表

**命名规范：**
- `architecture_overview.png` - 系统架构总览
- `database_er_diagram.png` - 数据库ER图
- `user_flow.png` - 用户流程图
- `game_loop.png` - 游戏循环图
- `ai_generation_flow.png` - AI生成流程图

### screenshots/ - 系统截图

用于存放系统运行时的截图：

- 客户端界面截图
- 游戏运行截图
- API文档截图
- 数据库管理截图
- 测试结果截图

**命名规范：**
- `login_page.png` - 登录页面
- `game_play_01.png` - 游戏画面1
- `api_docs.png` - API文档页面
- `database_tables.png` - 数据库表结构

### references/ - 参考资料

用于存放参考文献和学习资料：

- 相关论文PDF
- 技术文档
- 参考代码片段
- 其他参考资料

## 📝 论文材料准备清单

### 必需材料

| 类型 | 内容 | 状态 |
|------|------|------|
| 架构图 | 系统整体架构图 | ⬜ 待完成 |
| ER图 | 数据库实体关系图 | ⬜ 待完成 |
| 流程图 | 核心业务流程图 | ⬜ 待完成 |
| 截图 | 系统功能截图 | ⬜ 待完成 |
| 测试图 | 测试结果截图 | ⬜ 待完成 |

### 建议的图表

1. **系统架构图** - 展示客户端、服务端、数据库、AI服务的关系
2. **网络通信流程图** - 展示HTTP请求/响应流程
3. **数据库ER图** - 展示数据模型和关系
4. **用户注册/登录流程图** - 展示认证流程
5. **游戏主循环流程图** - 展示游戏运行逻辑
6. **AI内容生成流程图** - 展示AI调用和内容生成过程
7. **系统部署图** - 展示系统部署架构

## 💡 使用建议

1. 截图时使用统一的分辨率和窗口大小
2. 图片命名清晰，便于后续引用
3. 保留原始高清图片，论文中可适当压缩
4. 定期整理和更新材料
